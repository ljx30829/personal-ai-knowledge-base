# Review Import Field Guide

Common review fields:
- product_handle
- product_title
- rating
- title
- body
- reviewer_name
- reviewer_email
- created_at
- photo_url or photo_path
- verified
- country
- reply

Safety notes:
- Do not expose reviewer_email in storefront code or public reports.
- Do not mark verified unless the source app/export proves it.
- Do not invent dates or locations.
- Keep app-specific import formats separate from general working CSVs.

Presentation patterns:
- Product page: rating summary near title, review cards below specs, UGC gallery after benefits.
- Homepage: aggregate proof and 2-4 short quotes only if true and owned.
- Wholesale page: installer/dealer quotes, project photos, repeat-order proof.
