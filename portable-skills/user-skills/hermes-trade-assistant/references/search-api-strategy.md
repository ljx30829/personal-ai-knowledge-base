# 搜索 API 组合策略

> 来源: 外贸助手 V0.1 设计过程中反复测试和修正的数据获客方案  
> 结论: 单一天气 API 不够，四个免费 API 组合可达到 6,500 次/月免费额度

---

## 为什么需要组合？

单一搜索 API 各有局限：
- Tavily 语义搜索强，但结果偏 AI 训练数据
- Serper.dev 速度快，但仅限 Google 索引
- Brave 有独立索引，但覆盖不如 Google
- Bing 覆盖 Microsoft 生态，但亚太和欧洲数据较强

**组合策略**: 并发调用 3-4 个 API，合并去重，取各自最优覆盖范围。

---

## 四个推荐 API

| API | 免费额度 | 特点 | 注册链接 |
|------|:--:|------|------|
| **Tavily** | 1,000/月 | AI 语义搜索，返回结构化 JSON，为 Agent 设计 | tavily.com |
| **Serper.dev** | 2,500/月 | Google 搜索结果，速度快，覆盖面广 | serper.dev |
| **Brave Search** | 2,000/月 | 独立索引，隐私优先，不被 Google 限制 | api.search.brave.com |
| **Bing Search** | 1,000/月 | 微软索引，补漏 Google 未收录页面 | microsoft.com/bing/apis |

**合计: 6,500 次/月**

---

## 分流策略

```
用户搜"找德国LED进口商"
    ↓
并发调用:
  → Tavily (语义搜索: 行业相关网站 + LinkedIn + B2B 目录)
  → Serper.dev (精确: 独立站 + 商业网站)
  → Brave (备选索引: 非 Google 收录的深度页面)
  → Bing (欧洲数据: .de 域名优势)
    ↓
合并去重 → 公司列表
```

### 分流规则

| 任务类型 | 优先 API | 原因 |
|----------|----------|------|
| "找XX国客户" | Tavily + Serper | Tavily 语义理解，Serper 精确匹配 |
| 特定域名搜索 | Serper.dev | Google site: 搜索最准 |
| 欧洲公司 | Bing + Serper | Bing 欧洲数据较强 |
| 验证公司存在 | Brave | 独立索引可做交叉确认 |
| 社媒验证 | Tavily | 语义搜索能关联社媒页面 |

## 备用方案

### Google Maps 浏览器搜索（不推荐规模化）

单市场（德/英/美）少量搜索可用，但：
- 跨国多语触发反爬（2026-06-07 实测: 12次后封禁）
- 返回 HTML 需手动解析，不稳定
- 仅适用于手动辅助模式

### Apollo.io（付费升级）
- 免费: 75次/月
- 付费: $49/月起 (2,500 credits/月)
- 优势: 直接返回邮箱 + 职位 + 电话

## 集成到产品的策略

| 用户层级 | 使用的数据源 | 月免费额度 |
|----------|-------------|:--:|
| 基础（免费） | Tavily + Serper + Brave + Bing | 6,500 搜索 |
| 高级（付费） | 以上所有 + Apollo.io | 6,500 搜索 + 邮箱获取 |

推荐逻辑：
1. 先用四合一搜索 API 找到公司官网 URL
2. 访问官网 → 提取公开邮箱
3. 如果官网无邮箱 → 展示 Apollo 付费入口"一键获取联系人"
4. 付费用户自动跳过步骤 2-3，直接通过 Apollo 获取完整数据
