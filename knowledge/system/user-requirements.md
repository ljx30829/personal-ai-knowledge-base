# 用户长期要求

## 总目标

- 用文件保存可迁移知识，使另一台电脑、另一个 Codex 或其他 AI 能在获得私有仓库访问权后继续工作。
- 覆盖外贸、独立站、ArmorHue、Yufeng、中转站、节点、技能、自动化、自媒体、蒸馏、研究方法和项目要求。
- 方案不付费、不依赖本机持续开机，不把知识公开；使用私有 GitHub 仓库同步。
- 知识库保存结论、规则、索引、证据路径与恢复步骤，不复制所有大文件和原始业务数据。

## 开始工作的固定顺序

1. 读取当前仓库或工作区的 `AGENTS.md`。
2. 读取 `TASK_STATE.md` 或 `PROJECT_STATE.md`。
3. 读取相关工作流、运行手册、自动化记忆和最新日期证据。
4. 检查已有文件后再生成或修改，避免覆盖用户工作。
5. 有意义的进展写回状态文件，包括完成项、证据、阻塞和下一步。

## 事实与证据

- 证据优先，宁可保留较少的已验证内容，也不补造信息。
- 使用 `PASS`、`WATCH`、`FAIL`、`BLOCKED` 或 `UNVERIFIED`，并附证据路径和缺口。
- 程序退出码为 0、自动化为 `ACTIVE`、草稿已生成，都不等于业务结果健康、已发送、已上线或已成交。
- 不虚构联系人、客户兴趣、价格、产品参数、认证、仓库、公司信息、TDS、质保、评论、销量、分析数据、权限或平台状态。
- 来源主张、AI 推断和独立验证必须分开记录；带日期的状态会过期，复用前应复查。

## 隐私与安全

- 不读取、复制、展示或提交密码、令牌、Cookie、密钥、浏览器资料、邮箱正文或原始客户敏感记录。
- 不把凭据写入仓库、任务包、日志、截图或对话。只记录变量名、配置位置和恢复步骤。
- GitHub 仓库必须是 `Private`，不得启用 GitHub Pages；创建后要回读可见性再推送。
- 大型日志、CSV、网页镜像、图片、视频、压缩包和完整源代码留在原工作区，只记录摘要与路径。

## 授权边界

- 公开来源研究、只读检查、本地草稿和本地验证通常可以执行。
- 真实邮件、私信、评论、WhatsApp、社交发布、表单提交、付款、账号变更、部署、上线和 Shopify 在线店铺修改，需要当前任务的明确目标与操作授权。
- 外贸发现与社交准备默认不发送。遇到弱验证、验证码、429 或平台限制时，保持 `WATCH` 或 `BLOCKED_NO_SEND`。
- 社交工作是人工审核的执行队列，不是批量垃圾发送器；准备完成不等于已经触达。
- Shopify 操作应优先使用已配置的开发工具，但未明确提供目标商店及当次授权时不得连接或修改线上店铺。
- Shopify 接入文档必须区分主题 CLI、Admin API 和 Storefront API，并明确认证、最小权限、只读验证、未发布上传和正式发布的不同状态。
- 节点文档必须区分 v2rayN 客户端、VPS 传输入口和上游住宅出口，给出配置字段、五层验证和排障步骤，但不得保存节点秘密。

## 安装与存储

- 安装工具、包、模型、浏览器或 Docker 镜像前，先估算下载量、安装体积、默认位置和 D: 替代位置。
- 大型安装先确认；C: 空间有限，优先使用 `D:\codex\.cache`、`D:\codex\tools` 和项目本地环境。
- 当前知识库不需要付费服务、常驻电脑、数据库、MCP 服务或模型下载。

## 跨设备可执行性

- 技能名称清单不等于技能可用；经用户确认后用默认 dry-run、秘密过滤和 SHA-256 清单导出技能，目标端不得覆盖同名文件。
- 自动化必须按脱敏规格重建，先暂停/dry-run；缺少元数据的三个目录保持 `UNKNOWN`，不补造或删除。
- 克隆本知识库不等于恢复 `D:\codex` 等项目；项目应分别使用 Private 仓库、Codex task pack 或审阅归档迁移。
- 中转站、Docker 和定时执行需要实际在线运行环境；GitHub 只保存知识和代码，不提供常驻服务。
- 外贸实发、自媒体发布、客户访谈和线上变更在新设备上仍需重新满足当次授权与业务门。
- Git 同步前后都要检查状态、验证、断链和秘密；不能用破坏性命令覆盖另一台设备的改动。

## 独立站与视觉

- 先检查 `IMAGE_WORKFLOW.md` 和 `PROMOTION_WORKFLOW.md`；按工作区现有流程执行。
- 产品、颜色、材质、车型和用途必须精确匹配。收集多个候选，拒绝错色、水印、拉伸、低质量和无关图。
- 竞品只用于结构、视觉层级和转化逻辑参考；不复制竞品代码、图片、商标、原文或评论。
- ArmorHue 默认方向是高端汽车工业感与工厂直供的批发可信度，避免廉价模板、占位符、重复图片、虚假评价和未经授权素材。
- 视觉实验应生成候选并完成桌面与移动端截图审核，不得静默推到线上。

## 外贸与自动化

- 线索发现、邮件发送、社交准备和监督状态必须分开，不能用准备数量冒充发送数量。
- 只有明确的最终发送记录可计入发送；阻塞、演练、草稿和待审核记录不计入。
- 自动化内存和项目 `TASK_STATE.md` 应同步记录同一批次的结论、证据与下一步。
- 当前发送者、邮箱可用性、抑制清单、去重和节奏必须在实际发送前重新验证。

## PowerShell 与本机约定

- `$env:CODEX_HOME` 可能为空；自动化状态应使用已验证的绝对路径并在写后回读。
- 当前 PowerShell 不假设支持空值合并语法；使用明确的空值判断。
- 对带 UTF-8 BOM 或混合换行的状态文件，先读取编码和文件头，再做保留式更新。

## 未知项

- 平台登录状态和当前凭据不写入知识库，操作时现场确认；仓库 owner、名称和非秘密 URL 可以记录，以便跨设备恢复。
- 各项目最新业务状态以对应 `projects/` 页面及原工作区最新证据为准。
