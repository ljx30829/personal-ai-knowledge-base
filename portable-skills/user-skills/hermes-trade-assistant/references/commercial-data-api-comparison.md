# 商业 B2B 数据 API 方案对比

> 目标: 外贸助手全球客户搜索 + 联系信息获取  
> 日期: 2026-06-07  
> 背景: Google Maps 免费浏览器抓取在跨越多国多语言搜索时（12次+）触发反爬，不适合全球规模化商用产品。商业 API 是正规可规模化的替代方案。

---

## 推荐: Apollo.io

**数据库**: 2.75亿联系人 + 3000万公司，全球覆盖
**免费**: 75 credits/月（邮件查找消耗）
**付费**: Basic $49/月 (2,500 credits/月) | Professional $79/月 (4,000 credits/月)
**API**: 完整 REST API，可直接集成到 Hermes
**外贸优势**: 可按国家/行业/公司规模筛选；非美国数据较好

**对 V0.1 的适用**:
- 免费层 75次/月刚好够内测用户试用
- API 集成后 Hermes 可直接搜公司 + 拿邮箱
- 用户自注册 Apollo 账号并填 API Key

**最佳搭配**: Apollo（找公司+邮箱） + Hunter.io（验证邮箱准确性）

---

## 备选: Snov.io

**优势**: 最便宜的付费起点($30/月)、免费50次/月
**劣势**: 数据库不如 Apollo 大，非美国数据质量参差不齐
