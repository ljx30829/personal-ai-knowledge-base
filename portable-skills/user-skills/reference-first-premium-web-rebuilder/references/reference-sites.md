# Reference Sites

Use these references for learning rendered structure, hierarchy, motion rhythm, mobile behavior, and commercial adaptation. Do not copy source code, logos, trademarks, client work, reviews, protected copy, or unlicensed images into final public deliverables.

## Primary Visual/Motion References

### Viktor Oddy

- URL: https://viktoroddy.com/
- Social: https://x.com/viktoroddy
- Best for: sharp taste calibration, editorial spacing, restrained first-screen confidence, non-template art direction.
- Use when: the target page feels generic, overbuilt, or visually uncertain and needs stronger visual judgment.
- Avoid copying: personal identity, writing, portfolio content, exact visual identity, screenshots as final assets.
- Commercial adaptation note: translate the restraint and spacing into product, service, or B2B proof without making the business unclear.

### Cuberto

- URL: https://cuberto.com/
- Best for: premium motion, large type systems, hover interactions, scroll rhythm, confident page pacing.
- Use when: the target needs motion polish, memorable first impression, or strong interactive product/service storytelling.
- Avoid copying: agency copy, project/customer work, source code, motion details that obstruct conversion.
- Commercial adaptation note: keep rhythm and confidence, but keep CTAs, forms, product information, and buyer paths easy to find.

### Locomotive

- URL: https://www.locomotive.ca/
- Best for: mature agency structure, refined typography, editorial flow, navigation quality, service/capability pacing.
- Use when: the target needs premium but credible commercial structure.
- Avoid copying: client cases, copy, visuals, agency identity.
- Commercial adaptation note: useful bridge between expressive design and B2B/service clarity.

### Lusion

- URL: https://lusion.co/work
- Best for: immersive work grids, interaction craft, WebGL-style energy, cinematic transitions.
- Use when: the page needs advanced motion or an immersive product/case-study showcase.
- Avoid copying: project visuals, case studies, technical effects that are too heavy for the target.
- Commercial adaptation note: use selectively; reduce experimental friction for ecommerce, quote, or factory pages.

## Choosing A Reference

- Need stronger first impression: Viktor Oddy, Cuberto, Locomotive.
- Need motion rhythm: Cuberto, Lusion, Active Theory, Dogstudio.
- Need B2B/service clarity: Locomotive, PackMint, Accredo, Flexiarte.
- Need packaging taxonomy: Rootree, CarePac.
- Need QR/connected packaging: ePac Connected Packaging.
- Need immersive brand storytelling: Lusion, Unseen Studio, Active Theory.
- Need premium service/case-study structure: Locomotive, Ovra Studio, HC Design.
- Need anti-template taste calibration: Viktor Oddy plus a commercial reference.

## Required Capture Set

For each selected reference:

- Desktop first viewport.
- Desktop full page.
- Mobile first viewport.
- Mobile full page.
- Navigation/menu states.
- Hover states for important interactive elements.
- Scroll/motion notes or recordings.
- Form states if used as form reference.

## Adaptation Boundary

Allowed:

- Rebuild layout proportions from observation.
- Recreate module order and responsive behavior.
- Recreate motion rhythm with original code.
- Use screenshots for private side-by-side learning and comparison.
- Translate portfolio or commercial mechanics into target-brand pages.

Not allowed:

- Copy source code.
- Copy logos, brand marks, project/customer names, reviews, or case studies.
- Copy protected copywriting.
- Use unlicensed reference images as final public assets.
- Present reference-owned proof as target-owned proof.
