# IMAGE-FIRST

Purpose: fix ugly surfaces by making the product image, layout system, responsive order, and motion carry the design. Do not decorate weak pages; rebuild the visual system around product proof.

## Rules

- Start from screenshot evidence and AUDIT findings.
- Use peer/reference sites for structure and quality, not copied assets or copy.
- Product and factory images must be real, authorized, traceable, or clearly marked as replacement-needed.
- Do not use a product link without a product image.
- Do not let all product cards or PDPs share one generic visual.
- Keep motion purposeful, light, and reduced-motion safe.
- Verify desktop and mobile after each meaningful visual pass.

## 23 Design Commands

1. `reference-lock`: choose page-type references and state what is being borrowed.
2. `image-led-hero`: make the first viewport show the product/category/factory reality.
3. `whitespace-map`: normalize section padding, card gaps, and breathing room.
4. `type-system`: unify font family, heading scale, body rhythm, and label weight.
5. `color-discipline`: limit palette roles and remove cheap/default color clashes.
6. `grid-rhythm`: align section grids, columns, media frames, and text blocks.
7. `product-card-ratio`: lock card image aspect ratios and CTA placement.
8. `catalog-complete`: ensure every product link has image, title, use, cue, CTA.
9. `pdp-gallery-first`: make PDP start with gallery plus product-specific summary.
10. `pdp-spec-depth`: add use, format, material, print, finish, RFQ checklist.
11. `content-trim`: remove filler, AI phrasing, internal risk notes, and repeated copy.
12. `factory-proof-tone`: show credible process context without fake claims or disclaimers.
13. `rfq-path`: make inquiry fields match buyer packaging decisions.
14. `mobile-order`: reorder mobile content as image, title, specs, CTA, checklist.
15. `sticky-safe`: prevent fixed bars from covering content or forms.
16. `nav-logo-trust`: verify logo, nav hierarchy, active routes, footer trust.
17. `image-manifest`: record source, use, reuse, and replacement status for images.
18. `responsive-crop`: use stable aspect ratios and object-fit for every key image.
19. `hover-purpose`: add only useful hover states for cards and galleries.
20. `motion-restraint`: use subtle reveals/transitions; support reduced motion.
21. `editability-pass`: add schema settings/blocks for critical sections.
22. `contrast-and-taps`: check contrast, tap targets, line wrapping, and overflow.
23. `evidence-loop`: rerun screenshots, route/image scans, theme checks, and text scans.

## Execution Order

1. Run `AUDIT` or read its latest findings.
2. Apply commands 1-7 to establish the site-wide visual system.
3. Apply commands 8-13 to Products, PDP, Factory, RFQ, Contact.
4. Apply commands 14-20 to mobile and interaction polish.
5. Apply commands 21-23 before calling any work complete.

## Output

Report changed surfaces, commands applied, screenshots/checks produced, and remaining blockers. Do not claim completion without evidence.
