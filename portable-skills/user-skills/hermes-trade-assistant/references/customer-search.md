## 一、Google 搜索 — 43种方法

### 第一类：基础搜索（12种）

1. **Importers法**: `产品名 + importers`（用目标国家Google域名如 google.co.uk, google.de）
2. **引号精准法**: `"产品名 importer"`（双引号强制精确匹配）
3. **Distributor法**: `产品名 + distributor`
4. **角色词扩展**: buyer, company, wholesaler, retailer, supplier, vendor（及其复数）
5. **Price法**: `price + 产品名`（找在卖这个产品的人）
6. **Buy法**: `buy + 产品名`（找在采购的人）
7. **国家限制**: 以上方法 + 国家名
8. **关联产品法**: `产品名 + 关联产品名`（如 LED light + driver）
9. **Market Research法**: `产品名 + market research`
10. **著名买家法**: `产品名 + 行业龙头公司名`（找到龙头客户的竞争对手）
11. **右侧广告法**: 搜索后观察Google右侧广告（投广告的也是潜在客户）
12. **行业展览法**: `产品名 + trade show` 或 `产品名 + exhibition`

### 第二类：高级搜索（6种）

13. **Title精准搜索**: `allintitle:产品名 importer`（网页标题必须包含这些词）
14. **查找反链**: `link:大客户网站`（谁链接了这个客户）
15. **引用搜索**: `"大客户网址"`（谁提到了这个客户）
16. **网址含公司名**: 使用高级搜索，在"网页内的网址"搜索大客户名称
17. **多语言搜索**: 用法语/德语/西班牙语搜产品名（如 "éclairage LED"）
18. **专业文档搜索**: `filetype:pdf 产品名 importer`

### 第三类：专业网站（6种）

19. **网址目录**: Yahoo Directory / DMOZ.org
20. **企业名录**: Kompass.com / tgrnet.com
21. **进口商目录**: 搜索 `importers directory` 或 `distributors directory`
22. **行业网站**: `行业名 + industry` 或 `行业名 + portal`
23. **综合商贸网**: Alibaba / Made-in-China / Global Sources
24. **黄页网站**: 各国本地黄页（如 gelbeseiten.de 德国黄页）

### 第四类：政府与机构（4种）

25. **商务部世界买家网**: win.mofcom.gov.cn
26. **商务部驻外机构**: 各国经商参处网站
27. **进出口协会/商会**: 各国 Chamber of Commerce
28. **各国行业协会**: 如美国照明协会、德国电子工业协会

### 第五类：其他方法（15种）

29. **行业巨头渠道**: 大品牌的经销商名录
30. **Alexa工具**: 通过行业网站的Alexa排名发现相关网站
31. **海关数据**: 最重要！真实提单记录（ImportYeti 免费 / ImportGenius 付费）
32. **商务部进口商信息卡**
33. **物流渠道**: 船公司、快递公司、货代掌握的进口商信息
34. **国际招投标信息**
35. **LinkedIn搜索**: `site:linkedin.com "product" "country"`
36. **Facebook群组**: 加入行业群组，观察讨论
37. **YouTube**: `产品名 + review` 查看评论者
38. **Instagram**: `#产品名` 标签搜索
39. **行业论坛**: 观察谁在讨论采购需求
40. **问答网站**: Quora "Where to buy XX"
41. **地图搜索**: Google Maps 搜 `产品名 importer near 城市`
42. **Whois查询**: 查目标客户网站的注册信息
43. **招聘网站**: 公司招聘采购人员 = 正在扩大进口！

## 二、LinkedIn 开发攻略

### 基础操作
- 唯一在国内无需翻墙的海外社媒平台
- 搜索: 产品关键词 → 筛选 People/Companies → 查看 Profile
- 关键词技巧: 搜职位词（Purchasing Manager / Sourcing Director / Buyer）
- People Also Viewed: 每个人的 Profile 下方的推荐列表 = 更多潜在客户

### 主动开发
1. 先完善自己 Profile（专业头像 + 完整经历 + 行业关键词）
2. 加目标客户为好友（个性化邀请消息，不要用默认模板）
3. 加了好友后不要马上推销，先互动（点赞/评论帖子）
4. 建立信任后再发 InMail 或要求转介绍

### 被动开发
1. 发布行业相关内容（趋势、见解、案例）
2. 加入行业 Groups 并积极参与讨论
3. 让客户通过内容找到你

### Sales Navigator（付费）
- 高级搜索过滤器（公司规模/行业/地区/职位）
- 保存 Lead 和 Account 列表
- 实时提醒目标客户动态

## 三、Facebook 开发

### 思维纠正
- **错误1**: FB = Alibaba（把FB当产品广告墙发） → 没人理你
- **错误2**: FB = 黄页（只搜索买家） → 效率低下
- **正确**: FB = 社交平台，先建立关系，再谈生意

### 实用步骤
1. **完善个人资料**: 真人头像，专业背景，让人信任
2. **加好友策略**:
   - 朋友的朋友（先加圈内人，再扩展）
   - 按条件搜索（学校/公司/行业）
   - 吸引别人加你（在群组活跃，用行业关键词）
3. **内容运营**:
   - 个人主页定期更新（不要只发广告）
   - 写日志 = 软文
   - 状态更新 + 表情符号增加可见性
4. **群组营销**: 加入行业 Groups → 回答问题 → 建立专家形象 → 客户主动找
5. **关联网站**: 网站加FB分享按钮 + FB页面链接

## 四、WhatsApp 开发

### 优势
- 全球 20 亿用户，即时通讯回复率远超邮件
- 适合中东、南美、东南亚、非洲客户

### 获取号码
1. 海关数据（公司名 → Google搜电话）
2. LinkedIn 联系人信息
3. 展会名片
4. Google Maps 商家信息
5. 公司官网 Contact Us 页面

### 开场白技巧
- 简短自我介绍（谁、什么公司、做什么产品）
- 一句话提供价值（如: "我们有XX产品的新款，比市场价低20%"）
- 不要一上来就发产品目录
- 对方回复后再深入沟通

### 最佳沟通时间
对方当地时间 9:00-11:00 或 15:00-17:00

## 五、海关数据挖掘

### 为什么最重要
- 这是真实提单记录，不是爬虫数据，不是推测
- 可以看到: 进口商公司名、进口频次、量级、供应商来源、HS编码

### 免费资源
- **ImportYeti.com**: 搜索美国进口记录（免费）
- **加拿大海关**: ic.gc.ca 进口商数据库
- **各国公开海关数据**: 部分拉美国家公开进口商信息

### 挖掘联系方式技巧
1. 拿到公司名 → Google搜索 → 找官网
2. 官网找 Contact / About Us → 获取邮箱和电话
3. LinkedIn 搜索公司名 → 找采购负责人
4. Hunter.io 验证邮箱格式
5. 如果没有直接邮箱 → 用 "姓名+公司域名" 推测 → 验证

## 六、展会开发

### 展前
- 获取参展商名录（展会官网通常有 Exhibitor List）
- 筛选目标客户（按国家、产品类别）
- 发送邀约邮件: "We'll also be at XX exhibition, would love to meet you at Booth XX"

### 展中
- 快速记录: 每个客户的需求、关注点、预算
- 拍照名片 + 备注（当晚整理，不然会忘）
- 标记优先级: A（立即跟进）/ B（一周内）/ C（保持联系）

### 展后
- **24小时内**发第一封跟进邮件
- 附上展会照片/产品资料
- 按优先级分批联系
- 不要让名片在抽屉里吃灰

## 七、客户背景调查

### 8种调查方法
1. **官网**: 看 About Us / Products / News → 了解业务范围
2. **Google搜索**: 公司名 + 新闻 → 了解最新动态
3. **Google Maps**: 看公司实景 → 判断规模（是办公楼还是住宅？）
4. **Whois**: 查域名注册时间 → 新域名警惕
5. **LinkedIn**: 查公司规模、员工数量 → 判断实力
6. **海关数据**: 查进口记录 → 确认是否真的做进口
7. **社交媒体**: Facebook/Instagram → 了解市场定位
8. **信用报告**: 邓白氏 / 中信保 → 查信用评级
