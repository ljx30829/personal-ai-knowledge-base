# Anti-AI Template Checklist

## Hard Gate

Do not call the work complete unless the page passes this gate.

## PASS Conditions

- Reference screenshots exist.
- Target before screenshots exist.
- Side-by-side screenshots exist.
- Difference table exists.
- Each claimed page type has a reference source and page-specific evidence, or an explicit documented inheritance from a closely equivalent passed page.
- Representative page passes visual comparison before full-site expansion.
- Desktop checked.
- Mobile checked.
- No horizontal overflow.
- All key images have `naturalWidth > 0`.
- Key images have nonzero rendered dimensions and are not blank, hidden, broken background images, or blocked by overlays.
- No broken images.
- No low-quality SVG hero/product placeholders.
- No fake metrics, fake ratings, fake reviews, fake badges, fake client logos, or fake certifications.
- No repeated generic card grids.
- No huge AI-template hero headline.
- No template-style dark/green/black background used without direct reference evidence.
- No cloned reference brand assets in final public output.
- Forms are usable.
- Pending or intentionally different items are documented.

## FAIL Conditions

- No reference screenshots.
- No side-by-side evidence.
- "Inspired by" without visible screen replication.
- Implementation started before reference and target-before screenshots were captured.
- Batch-generated pages with the same layout and swapped headings.
- Mobile overflow.
- Broken major images.
- Low-quality major images.
- Decorative form that cannot be used.
- Fake commercial proof.
- The result still looks like an AI landing page.

## High-Risk AI Template Signals

- Repeated rounded cards with icons and generic paragraphs.
- Oversized hero text with no reference-matched proportion system.
- Generic dark, green, black, gradient, or glassmorphism background used as the main premium device.
- Low-quality SVG illustrations where product, process, factory, service, or brand visuals are required.
- Every section has the same rhythm.
- Vague claims such as "premium", "trusted", "innovative", or "industry-leading" without evidence.
- Mismatched image styles across the same page.
- Stock-looking visuals that do not match the target product or service.
- Inconsistent radius, spacing, alignment, or typography.
- Random motion not tied to reference behavior.
- Mobile layout that merely collapses desktop without preserving hierarchy.
- Navigation or footer feels unfinished.

## Evidence Questions

Ask:

- What reference screenshot proves this structure?
- What side-by-side image proves the target is close?
- Which difference-table rows remain pending?
- Which differences are intentionally different and why?
- Were desktop and mobile both checked?
- Did the browser prove images load?
- Did the browser prove key images render at visible dimensions?
- Did the browser prove no horizontal overflow?
- Did forms remain usable?

## Originality And Legal Safety

Final public output must not retain:

- Reference logos.
- Reference trademarks.
- Reference client/customer cases.
- Reference reviews.
- Reference copy.
- Unauthorized competitor images.
- Copied source code.

Final public output may use:

- Target-owned assets.
- User-provided authorized assets within the authorization scope.
- Licensed assets.
- Supplier-authorized assets.
- Clearly reusable assets.
- Newly produced or generated target-brand assets.

## B2B And Factory Credibility

Premium but credible means:

- Concrete capabilities.
- Real product/process/factory/quality imagery when available.
- Clear quote/contact path.
- Specific buyer-relevant information.
- Unknown claims marked pending instead of invented.

Fail the work if visual polish hides missing proof.
