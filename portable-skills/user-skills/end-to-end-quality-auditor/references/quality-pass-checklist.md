# Quality Pass Checklist

Severity:
- High: blocks purchase/inquiry, breaks layout, shows wrong brand, leaks secret, uses fake/copy proof.
- Medium: hurts trust, mobile usability, product clarity, speed, SEO, or image quality.
- Low: polish issue that should be tracked but does not block launch.

Site checks:
- Home page loads.
- Product page loads.
- Collection/search route loads.
- Cart/contact routes load.
- Mobile and desktop screenshots exist.
- No Liquid error.
- No horizontal overflow.
- No broken key images.
- No old numbers, old brands, competitor names, or placeholder text.

Image checks:
- Correct color/material/finish.
- Correct product context.
- No watermark/marketplace UI.
- Traceable source or generation note.

Final answer:
- What changed.
- What was verified.
- What evidence files exist.
- What remains blocked or risky.
